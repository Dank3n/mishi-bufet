# Mishi Bufet

Website multi-pagini pentru **Mishi Bufet** — restaurant tip bufet asiatic & sushi train lângă Mega Mall, București.

## Stack

- Next.js (App Router) + TypeScript
- Tailwind CSS v4
- Framer Motion
- Lucide icons

## Rulare

```bash
npm install
npm run dev
```

Deschide [http://localhost:3000](http://localhost:3000).

## Pagini

| Rută | Conținut |
|------|----------|
| `/` | Hero + Sushi Train, Live Bufet, prețuri, Mishi Vibe, preview meniu |
| `/meniu` | Meniu editorial digital |
| `/despre` | Atmosferă / lookbook |
| `/rezervari` | Formular rezervări |
| `/contact` | Locație & contact |

## Design

Neo-noir / cyberpunk japonez — negru `#0a0a0a`, accent roșu `#FF1E1E`, tipografie editorială (Cormorant Garamond + Outfit).
